Présentation du projet

ce projet consiste a analyser les performances commerciales a l'aide de power Bi, a partir de données de vente.
Objectifs de l'analyse
analyser le chiffre d'affaires brut et net,
suivre le marge brute et le taux de marge,
mesurer les quantités vendues,
analyser les remises accordées,
comparer les performances des produits,
suivre l'évolution des ventes dans le temps.

Outils utilisés

Microsoft Excel
Power Bi
SQL Server
